# program-using-tracker
This program tracks some of your programs. It tracks the time how long your programs are open!

This program is a simple usage tracker that only tracks the time of programs while they are actively open and running. It does not track your usage when the program is closed.

### How to Start

1. Download all of the files
2. Extract them if they are in a ZIP file
3. Run `start.bat`
4. The tracker will start automatically and begin tracking the supported programs while they are open

### Currently Tracked Programs

The tracker currently supports:

* Among Us
* CapCut
* Discord
* Spotify
* WhatsApp
* Firefox
* Minecraft Java Edition
* Steam
* NoRiskClient, a Minecraft client similar to Badlion
* Voicemeeter

You are also free to customize the tracker yourself. If you have access to the source code, you can add new programs to the tracker or remove existing ones whenever you want.
